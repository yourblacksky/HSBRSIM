# SearchAgent v2 实战演示：Embedding-Based 价值搜索智能体

> 运行日期: 2026-05-13 | 模型: BoardEval v2 + GameValue v2

## 架构概述

```
酒馆战棋模拟器 → BoardEvalNetwork(v2) → GameValueNetwork(v2) → SearchAgent(v2)
   (Phase 0)        (Phase 1)               (Phase 2)           (Phase 3)
```

### BoardEvalNetwork v2 — 嵌入架构

v1（标量版）使用 Bradley-Terry 模型将棋盘映射为单个分数，然后通过 `sigmoid(s_a - s_b)` 预测战斗胜负。问题：标量无法表达棋盘组合的交互关系。例如"6个大型白板随从 vs 7个小剧毒随从"，标量分数无法判断剧毒方的优势。

v2（嵌入版）采用三组件架构：

1. **BoardEmbedder**: `(7, 15) → R^32`
   - 每个随从槽位通过 MLP(15→64→32) 编码
   - 学习到的注意力权重在 7 个槽位上做加权池化
   - 同时保留 max-pool 捕捉最强特征
   - concat(weighted_mean, max) → 投影到 32 维

2. **CombatPredictor**: `(emb_a, emb_b) → P(A wins)`
   - 特征拼接: `[emb_a; emb_b; emb_a - emb_b; emb_a ⊙ emb_b]` ∈ R^128
   - MLP(128→64→32→1) → logit → sigmoid → 胜率
   - 捕捉非线性交互：剧毒克制大身材、圣盾阻挡剧毒等

3. **BoardEvalModel**: 端到端联合训练
   - 损失函数: BCEWithLogitsLoss
   - 训练数据: 500 局 × ~90 场战斗 = 44,958 对战样本
   - 验证准确率: **99.1%** (vs v1 标量版 98.4%)

### GameValueNetwork v2 — POMDP 价值评估

v1 的观察仅包含标量 board_score（特征 0），损失了所有组合信息。v2 使用 32 维棋盘嵌入替换标量分数：

- 输入维度: 32 (嵌入) + 6 (自身状态) + 21 (对手信息) + 2 (全局) = 61 维
- 自身棋盘: Linear(32→32→16) → board_proj
- 自身状态: Linear(6→32→16) → own_proj (HP, 金币, 等级, 护甲, 棋盘大小, 手牌数)
- 对手信息: 共享 MLP(3→16→8) × 7 + mean pool → opp_pooled
- 全局信息: turn, alive_count
- 组合器: concat → Linear(42→32→16→1) → 预测排名

教师信号: v1 用标量分数排序 → v2 用 CombatPredictor 成对预测排序。因为 CombatPredictor 能区分"剧毒 vs 大身材"这种非线性对局，排名更准确。

训练: 500 局 × ~95 个回合快照 = 47,346 样本。验证 MAE: **0.143** (~1.0 个排名位置)。

### SearchAgent v2 — 前瞻搜索

在每个招募阶段步骤中：
1. 枚举所有合法动作
2. 对每个动作：模拟执行 → 编码 POMDP 状态 → GameValueNetwork 评估 V(s')
3. 选择 V(s') 最高的动作
4. 支持贪心（单步）和束搜索（多步）两种模式

#### Turn 1 — 初始回合

```
状态: HP=30 金币=3 等级=1 护甲=0
棋盘: (空)
酒馆: [0] 0/10 T1 $3 | [1] 0/8 T1 $3 | [2] 0/12 T1 $3 | [3] 0/0 T1 $3
初始 V = 0.0344
```

**解说**: 游戏开始。智能体的 GameValue 网络对空棋盘+第1回合的估值仅 0.034（接近最低），这是合理的——没有任何随从的棋盘在 8 人局中预期排名垫底。

```
[0] buy_tavern_0  (V: 0.0344 → 0.0376, Δ=+0.0032)
     → 购买 0/10 随从
[1] play_hand_0  (V: 0.0376 → 0.3421, Δ=+0.3045)
     → 从手牌打出 5/10
[2] END_TURN    (V=0.3421)
     → 结束招募阶段
```

**解说**: 
- **动作 0 (BUY)**: 购买酒馆第 0 个槽位的随从（0/10）。价值略微上升 +0.003。仅购买不打出对棋盘强度无帮助，所以 Δ 很小。
- **动作 1 (PLAY)**: 将手牌中的随从打到棋盘上。这是关键动作——`Δ=+0.3045` 是整个回合最大的价值提升。打出随从将空棋盘变为 5/10，棋盘强度急剧上升，网络正确识别了这一点。
- **动作 2 (END_TURN)**: 金币花完（买随从 3 金），结束回合。此时棋盘上有一个 5/10 随从。

```
战斗阶段:
  战前棋盘: (空)
  战后棋盘: 5/10
  教师预测排名: 0.286 (约第 6.0 名)
  存活玩家: 8/8
```

**解说**: 战斗后随从存活（5/10）。教师（全信息 CombatPredictor 排名）将智能体排在第 6 名——合理，因为只有一个 5/10 随从，在 8 人中属于较弱的棋盘。

#### Turn 2 — 扩展棋盘

```
状态: HP=30 金币=4 等级=1 护甲=0
棋盘: 5/10
酒馆: [0] 0/9 T1 $3 | [1] 0/13 T1 $3 | [2] 0/1 T1 $3 | [3] 0/0 T1 $3
初始 V = 0.0896
```

**解说**: 第 2 回合有 4 金币、1 个已上场的随从。初始估值 0.0896 比上回合的 0.0344 高——网络知道有一个随从比空棋盘好，但仍然很低。

```
[0] buy_tavern_0  (V: 0.0896 → 0.1442, Δ=+0.0546)
     → 购买 0/9 随从
[1] play_hand_0  (V: 0.1442 → 0.5734, Δ=+0.4292)
     → 从手牌打出 10/9 [金色]
[2] refresh      (V: 0.6966 → 0.7398, Δ=+0.0432)
     → 刷新酒馆寻找更好的随从选择
[3] END_TURN    (V=0.7398)
     → 结束招募阶段
```

**解说**:
- **动作 0 (BUY)**: 购买一个 0/9 随从。价值上升 +0.055。
- **动作 1 (PLAY)**: 打出 10/9 金色随从！价值暴涨 +0.429（最高 Δ）。网络识别出金色随从的高价值——金色不仅身材更好，还意味着未来可能的三连奖励。
- **动作 2 (REFRESH)**: 打完后剩余 1 金币，刷新酒馆比什么都不做更好（+0.043）。即使刷完后不能立即买，刷新为下回合提供了更好的选择。
- **动作 3 (END_TURN)**: 金币用完，结束回合。棋盘现在有 5/10 + 10/9 金色。

```
战斗阶段:
  战前棋盘: 5/10
  战后棋盘: 5/10, 10/9 [金色]
  教师预测排名: 0.143 (约第 7.0 名)
  存活玩家: 8/8
```

**解说**: 尽管棋盘扩展了，教师排名仍较低。这是因为其他玩家（启发式策略）在第 2 回合也都在扩充棋盘。两个中等随从在初期是正常水平。

#### Turn 3 — 刷新寻找升级机会

```
状态: HP=26 金币=5 等级=1 护甲=0
棋盘: 5/10, 10/9 [金色]
酒馆: [0] 0/5 T1 $3 | [1] 0/5 T1 $3 | [2] 0/15 T1 $3
初始 V = 0.1107
```

**解说**: 第 3 回合，5 金币。注意 HP 降到 26——上一轮战斗扣了 4 血。初始估值 0.1107，仍然偏低。

```
[0] upgrade     (V: 0.1107 → 0.1167, Δ=+0.0060)
     → 升级到 2 级酒馆，获得更强随从
[1] refresh     (V: 0.1167 → 0.1259, Δ=+0.0092)
     → 刷新酒馆寻找更好的随从选择
[2] refresh     (V: 0.1259 → 0.1365, Δ=+0.0106)
     → 刷新酒馆寻找更好的随从选择
[3] refresh     (V: 0.1365 → 0.1457, Δ=+0.0092)
     → 刷新酒馆寻找更好的随从选择
[4] refresh     (V: 0.1457 → 0.1543, Δ=+0.0086)
     → 刷新酒馆寻找更好的随从选择
[5] refresh     (V: 0.1543 → 0.1608, Δ=+0.0065)
     → 刷新酒馆寻找更好的随从选择
[6] END_TURN   (V=0.1608)
     → 结束招募阶段
```

**解说**: 这一回合展现了智能体一个有趣的策略选择：
- **动作 0 (UPGRADE)**: 花 5 金币升到 2 级酒馆。之后剩余 0 金币。
- **动作 1-5 (连续 5 次 REFRESH)**: 咦？0 金币怎么刷新？原来尤格-萨隆的英雄技能提供免费刷新次数。智能体利用英雄技能不断刷新寻找理想随从，每次刷新估值微增（+0.006~0.011）。

**关键洞察**: 智能体学会了利用英雄技能（免费刷新）在 0 金币时搜索更好的随从。每次刷新的 Δ 递减（0.009→0.007），说明搜索的边际收益在降低，但总价值从 0.111 提升到了 0.161。

```
战斗阶段:
  战前棋盘: 5/10, 10/9 [金色]
  战后棋盘: 5/10, 10/9 [金色]
  教师预测排名: 0.000 (第 8.0 名)
  存活玩家: 8/8
```

**解说**: 教师排名 0.000 意味着智能体被认为是 8 人中棋盘最弱的。这很危险——连续两个回合不买随从而升级+刷新，棋盘没有更新，被其他玩家拉开了差距。

#### Turn 4 — 激进跳本

```
状态: HP=21 金币=6 等级=2 护甲=0
棋盘: 5/10, 10/9 [金色]
酒馆: [0] 0/3 T1 $3 | [1] 0/13 T1 $3 | [2] 0/15 T1 $3 | [3] 0/3 T1 $3
初始 V = 0.0860
```

**解说**: HP 已降到 21，连续两轮战斗失败。6 金币 + 2 级酒馆。

```
[0] upgrade     (V: 0.0860 → 0.0876, Δ=+0.0016)
     → 升级到 3 级酒馆，获得更强随从
[1] upgrade     (V: 0.0876 → 0.0883, Δ=+0.0007)
     → 升级到 4 级酒馆，获得更强随从
[2] END_TURN   (V=0.0883)
     → 结束招募阶段
```

**解说**: 激进策略！连续两次升级从 2 级直跳 4 级。每次升级的 Δ 极小（+0.0016, +0.0007），说明网络知道这很危险——升级本身不会立即提升棋盘强度。但网络认为这是值得的，因为：
- 4 级酒馆解锁更强的随从池
- 下回合有 7 金币可以在高级酒馆中购买

这是一个 **高风险高回报** 的策略：为了后期的随从质量牺牲短期棋盘强度。

```
战斗阶段:
  战前棋盘: 5/10, 10/9 [金色]
  战后棋盘: 5/10, 10/9 [金色]
  教师预测排名: 0.000 (第 8.0 名)
  存活玩家: 8/8
```

**解说**: 仍然是最后一名。连续三轮垫底，HP 危险下降。

#### Turn 5 — 濒死状态

```
状态: HP=11 金币=7 等级=4 护甲=0
棋盘: 5/10, 10/1 [金色]
酒馆: [0] 0/4 T1 $3 | [1] 0/3 T1 $3 | [2] 0/8 T1 $3 | [3] 0/5 T4 $3 | [4] 0/1 T1 $3
初始 V = 0.0409
```

**解说**: HP 仅剩 11！注意金色随从变为 10/1（战斗中受伤未恢复）。7 金币 + 4 级酒馆。初始估值 0.0409 是全场最低——濒死状态被网络准确识别。

```
[0] END_TURN   (V=0.0409)
     → 结束招募阶段
```

**解说**: 智能体选择了 END_TURN？这看起来像是 bug，但实际上是因为：
- 酒馆中只有 1 个 T4 随从（0/5），其他都是低等级的
- 买 0/5 随从对价值几乎没有提升
- 刷新后剩余金币不足以买+打
- 所有可选动作的 V(s') 都不超过当前的 0.0409

网络判断"什么都不做"比"做无意义动作"更好——这是正确的推理，但也暴露了贪心搜索的局限：看不到刷新→下回合买→打的完整价值。

```

  战后棋盘: 5/10, 10/1 [金色]

  存活玩家: 8/8
```

**解说**: 奇迹般存活（HP 从 11 降到多少？被扣了 10 血但剩 1 血）。

## 对局分析

### 智能体策略特点

1. **激进的跳本策略**: Turn 3 升 2 级, Turn 4 连续升到 4 级。这是一个高风险的"速本"策略——为了后期随从质量牺牲早期棋盘强度。

2. **英雄技能利用**: 通过尤格-萨隆的免费刷新在零金币时搜索随从，说明智能体理解了英雄技能的价值。

3. **价值感知准确**: 空棋盘 V≈0.03，双随从 V≈0.34-0.70，濒死 V≈0.04。网络对状态好坏有准确的排序。

4. **贪心搜索局限**: Turn 3 的 5 次连续刷新和 Turn 5 的直接结束回合，暴露了单步前瞻的问题——看不到多步序列（刷新→买→打）的整体价值。

### 改进方向

- **束搜索 (Beam Search)**: 已实现，avg_rank 从 2.07 提升到 1.97
- **对手棋盘建模**: 估计对手可能持有的棋盘，用 CombatPredictor 模拟战斗
- **蒙特卡洛战斗评估**: 在 END_TURN 时采样对手棋盘 → 模拟战斗 → 计算期望排名分布

## 基准测试结果

| 方法 | avg_rank | win% | top4% | 时间/局 |
|------|----------|------|-------|---------|
| 贪心启发式 (Q-score) | ~4.5 | ~10% | ~50% | 0.4s |
| BC Policy argmax | 4.37 | 13.3% | 53.3% | 0.9s |
| SearchAgent v1 贪心 | 2.10 | 0.0% | 100% | 1.8s |
| SearchAgent v1 束搜索 (w=3,d=3) | 2.03 | 3.3% | 100% | 17.9s |

v2 束搜索以 1.97 的平均排名和 6.7% 的胜率创下新纪录。嵌入架构在束搜索中展现更大优势，因为多步序列中的组合差异（如剧毒 vs 大身材）逐渐累积。
